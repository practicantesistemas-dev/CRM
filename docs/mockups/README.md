# Mockups

Prototipos visuales para discusión, no código de producción. Abrir el `.html` en el navegador.

## segmentos-y-campanas.html

Propuesta de la vista **Segmentos y campañas**: filtrar afiliados y convenios por uso de
servicios + datos de la persona/empresa y, sobre ese mismo resultado, lanzar una campaña de
WhatsApp o correo, crear tareas o aplicar una etiqueta (envíos vía webhook de n8n).

Incluye además dos pestañas de contexto: **Embudos** (venta individual, renovación, activación
de uso) y **Resumen de uso** de servicios de Plan Liga. Datos de ejemplo, no cifras reales.
